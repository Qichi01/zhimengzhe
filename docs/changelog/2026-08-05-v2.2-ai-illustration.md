# V2.2 AI 关键场景配图

> 日期：2026-08-05

## 变更内容

- 新增关键场景配图开关，默认关闭并持久化到本地设置。
- 扩展故事 Prompt 与解析器，让 AI 标注普通/关键视觉场景。
- 兼容 `配图建议：关键`、`【配图建议】关键` 等格式漂移，并在解析与历史场景渲染两层清除内部标记。
- 开篇、新章节、结局强制视为关键场景；其余关键事件受四场景冷却限制。
- 新增智谱图片生成代理，默认使用免费 `CogView-3-Flash`，支持 `IMAGE_API_KEY` 与 `IMAGE_MODEL` 覆盖。
- 图片生成与场景后处理并行；失败不影响正文、选项或存档。
- 智谱临时图片由服务端下载，浏览器压缩为 WebP/Data URL 后写回 IndexedDB。
- 按图片文件签名校正供应商 CDN 偶发错误的 MIME 类型，并兼容本地代理自签名证书。
- 历史和最新场景的插图显示在正文上方，生成期间展示非阻塞占位。
- 增加设备级短时频率限制，避免异常密集请求。

## 环境变量

- 必需：`GLM_API_KEY`（可被 `IMAGE_API_KEY` 覆盖）
- 可选：`IMAGE_MODEL`，默认 `cogview-3-flash`

所有服务端 Key 均先执行 `trim()`，再取第一行并再次 `trim()`。
