# V3.0 阶段 1：沉浸事件运行时与题材界面

> 日期：2026-08-06
> 状态：首个可游玩沉浸切片已实现

## 本次交付

- V3 AI 回复新增结构化事件尾包，正文、选项与题材事件仍在一次主模型请求中完成。
- 事件尾包只进入白名单校验器，不允许模型输出 HTML、CSS 或任意组件；模型尾包缺失、格式损坏或事件非法时，正文和选项继续正常保存与显示。
- 事件 ID 由客户端按叙事帧重新命名，重复请求或读档重放不会重复发消息、道具、任务或未读数。
- 校园乙游首批接入私聊、校园论坛、日历、人物关系和人物档案；人物界面复用已生成或用户上传的头像。
- 无限流首批接入系统任务、队伍频道、背包、系统商店、玩家论坛和人物档案。
- 模块按题材和剧情事件逐步解锁，未读角标写入 IndexedDB；打开模块后清零，刷新页面仍保持已读状态。
- V3 文本请求上限单独提高到 1400 tokens，为正文、选项与事件尾包预留空间；V2 仍保持原有 800 tokens。
- 修复剧情回顾模式未加载历史场景的问题。

## 双端界面

- 手机端使用横向可滚动的情境导航和底部抽屉，兼容 44 px 触控区域、长内容滚动与底部安全区。
- 桌面端使用居中的右侧题材入口和 430 px 侧边抽屉，不挤压或复制正文状态。
- 校园界面使用柔和的手机视觉；无限流界面使用低饱和绿色系统视觉，两者共享同一事件和存档运行时。

## 验证

- TypeScript 类型检查通过。
- 本次修改文件的 ESLint 检查通过；项目全量 lint 仍包含既有的 `.agents`、生成目录和旧页面问题。
- 事件尾包解析与隐藏验证通过，内部 JSON 不会出现在正文。

- 1440×900 桌面视口通过校园论坛、无限流背包、侧边入口定位和抽屉滚动检查。
