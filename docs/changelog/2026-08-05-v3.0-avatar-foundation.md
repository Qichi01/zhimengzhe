# V3.0 阶段 0：人物头像基础能力

> 日期：2026-08-05
> 状态：已实现，待线上验收

## 本次交付

- V3.0 PRD 增加主要人物头像策略：用户上传优先于 AI 默认头像，失败时使用首字与主题色兜底。
- 新增统一人物头像类型，压缩后的资源随角色保存在 IndexedDB，刷新后可恢复。
- 新增默认头像生成 API，使用免费图片模型并限制请求频率；API Key 继续遵循去空格和去换行规则。
- 新增浏览器端头像处理：JPG、PNG、WebP，最大 5 MB，中心裁切并压缩为 512 × 512 WebP。
- 人物关系图节点和详情面板支持真实头像，并提供“上传替换”“重新生成”“恢复首字头像”。
- 主角由虚拟节点升级为本地角色档案，与主要 NPC 共用同一套头像能力。
- 新登场的主要 NPC 在后台尝试生成一次默认头像；失败不阻塞正文，且不会覆盖用户已经上传的图片。

## 兼容与降级

- 旧角色没有头像字段时无需迁移，继续显示首字头像。
- 旧乙游第一次打开游戏菜单时会在本地补建主角档案，但不会自动向外部图片服务发送旧设定；用户可主动生成或上传。
- 图片生成、压缩或保存失败时，关系、正文、选项和存档不受影响。

## 验证结果

- Next.js 16.2.10 生产构建通过。
- 新增文件定向代码检查通过；全仓检查仍存在与本次功能无关的历史错误。
- 真实浏览器验证通过：首字兜底、上传、压缩、关系图即时更新、刷新后恢复、桌面端与移动端布局。
- 外部默认头像生成未在本轮自动化浏览器验收中实际发送人物设定，需在获授权的测试数据环境中补验。
