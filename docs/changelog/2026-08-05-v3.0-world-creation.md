# V3.0 阶段 1：故事导入与世界档案创建

> 日期：2026-08-05
> 状态：首个可见切片已实现

## 本次交付

- 新建梦境默认推荐“沉浸模式 V3”，同时保留 V2 经典模式。
- V3 首批支持校园乙游与无限流两个题材入口。
- 支持手动粘贴故事内容，以及本地读取 TXT、MD、Markdown 文件，单文件上限 20 MB。
- 新增世界档案确认页，可编辑世界名称、简介、主角、主要人物、启用模块和视觉风格。
- 确认时在同一 IndexedDB 事务中创建游戏、故事来源、世界定义和角色档案。
- V3 游戏卡片显示“V3 沉浸”标识；校园乙游与无限流都可打开人物档案并替换头像。
- IndexedDB 升级到 v3，新增 `story_sources` 与 `world_drafts`，旧数据只升级仓库结构、不重建。
- 自动头像任务领取改为单一读写事务，避免 React 严格模式下重复生成。
- V3 选择“新的开始”时只清理剧情进度，保留原始故事、世界定义、人物档案和头像；删除游戏时才完整清理。

## 隐私与兼容

- 文件由浏览器直接读取，确认世界档案前不会创建游戏，也不会上传原文件。
- 原始故事来源保存在本机；游戏运行只使用确认后的世界简介和世界定义。
- 旧游戏保持 V2 模式，新功能不会自动迁移旧存档。

## 验证

- Next.js 16.2.10 生产构建通过。
- 浏览器完整走通：V3 新建、无限流选择、世界档案编辑、添加人物、确认创建、游戏卡片和人物档案。
- Markdown 文件的本地读取、格式识别、内容预览与来源提示通过。
- 测试游戏及关联 V3 数据通过应用删除流程成功清理。
