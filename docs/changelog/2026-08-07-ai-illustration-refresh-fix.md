# AI 配图触发与刷新恢复修复

> 日期：2026-08-07
> 状态：已实现，待线上验收

## 本次修复

- 修复阅读页刷新时把已有游戏误判为“新的开始”的问题。
- 无存档参数的正常阅读页现在会恢复 IndexedDB 中的当前场景；只有场景确实为空时才自动生成第一幕。
- 避免刷新后重复请求正文、重复生成图片以及重复消耗模型额度。
- 图片生成成功后检查本地写回结果；无法持久化时静默移除占位，正文、选项和存档流程不受影响。

## 验证

- 真实图片接口端到端通过：首场景配图请求返回 200，插图显示于正文上方。
- 刷新后正文、插图和选项从本地恢复，网络记录没有新增聊天或配图 POST。
- 模拟配图接口 502 时，正文和选项可继续使用，页面不显示内部控制文本或失败占位。
- TypeScript、定向 ESLint、配图决策测试和 Next.js 生产构建通过。
- 1440×900 桌面视口与 390×844 手机视口通过，手机端无横向溢出。
