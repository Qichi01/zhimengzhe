# 已知问题：关键场景没有触发 AI 配图

> 记录日期：2026-08-05
> 状态：已确认，延期排查
> 优先级：P1
> 影响版本：V2.2 AI 配图 / V3.0 基线

## 现象

- 开启“AI 场景配图”后，故事正文可以正常生成，但关键场景仍没有出现实际插图。
- 原先泄漏到正文中的内部标记（例如“配图建议：关键”）已经被过滤，当前不会再向用户展示。
- 图片生成 API 已做过单独请求验证并可返回图片，因此问题更可能位于关键场景判定、前端触发条件、请求时序或结果写回链路；这只是当前推断，尚未完成端到端定位。

## 当前降级行为

- 不显示“配图建议”等内部控制文本。
- 没有图片时不保留空白占位，不弹出阻断提示，正文和选项继续正常工作。
- 不自动高频重试，避免产生额外图片请求和成本。

## 后续排查清单

1. 记录解析后的 `illustrationSuggested`、本地设置开关和冷却判定结果。
2. 确认 `StoryReader` 在流式正文完成、场景入库之后是否进入图片请求分支。
3. 检查 `/api/illustration` 的请求、响应状态以及开发/生产环境差异。
4. 确认图片压缩、Data URL 转换、`updateSceneIllustration` 写回和重新读取链路。
5. 增加一条可控的关键场景端到端测试，并验证失败时仍保持静默降级。

## 解除条件

- 在本地与 Vercel 环境中，开启配图后可由一条可控关键场景稳定生成并显示插图。
- 刷新页面后插图仍存在，关闭开关时不发送图片请求。
- API 或图片处理失败时，不显示内部标记、错误占位或后端提示词。
